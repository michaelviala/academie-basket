# Déploiement sur le VPS (club30.cloud)

Ce dossier contient la config du **reverse proxy partagé**, à installer **une seule fois** sur le VPS.
Il sert de porte d'entrée pour tous les sous-domaines de `club30.cloud` (academie, pivot, etc.),
avec HTTPS automatique (Let's Encrypt).

Voir les instructions complètes données par Claude en conversation (DNS, installation Docker,
mise en route du proxy, puis de l'app `academie-basket`).
